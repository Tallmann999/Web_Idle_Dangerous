# Переработка Clicker Weapon Adventure → Idle Dangerous

| Было | Стало |
|---|---|
| Горизонтальный арсенал из пушек | Семь слотов надетых вещей по бокам вертикальной арены |
| Выбранное оружие и летящие пули | Прямой клик-удар, импакт и звук без оружия |
| Карточка покупки пушки | Компактное окно покупки/прокачки вещи |
| Внешняя карта мира и регионов | Вертикальный список комнат одного длинного подземелья |
| Золото с монстра | Золото плюс шанс получить компонент |
| Нет торгового возвращения | Выход в гильдию с сохранённой добычей |
| Арсенал как основной мотиватор | Экипировка, глубина, сдача добычи и репутация |
| Старые сохранения оружия | Отдельный ключ новой игры, без смешивания прогресса |

Сохранены исходные монстры, боссы, фоновые WebP, монета, звук попадания, локальный шрифт, тёмная зелёно-золотая палитра и стиль рамок. Компоновка рамок переписана под вертикальное соотношение, а не уменьшена целиком.

Сохранены 105 комнат, шесть диапазонов ярусов, десять врагов на комнату, босс каждые пять комнат, ручной переход и безопасный возврат после босса. После победы используется короткая заставка 1.8 с; старый пятисекундный фонтан монет не перенесён.

Перенесены исходные формулы HP и золота, гейты шести экономических единиц. Добавлен седьмой слот плеч на комнате 25. Предметы используют пять отдельных множителей ×2 и линейный прирост DPS за уровень; старые специализированные оружейные эффекты не перенесены.

Добавлены шесть типов трофеев, их стоимость на момент получения, продажа, сдача партий и три ранга репутации. Крафт и случайная заменяемая экипировка не реализованы.

Исходная документация сохранена в `docs/legacy-clicker-weapon/` только для истории. Актуальные требования изложены в корне `docs/`. Платформенные документы старой игры не означают, что новая сборка уже одобрена площадкой.
