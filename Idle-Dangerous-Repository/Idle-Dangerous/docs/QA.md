# Проверка Idle Dangerous — Phaser 4.2.1

12 сентября 2026. Проверяется активная игра `src/idle`, а не историческое однофайловое превью.

## Выполнено

- TypeScript: без ошибок.
- 15 Node-тестов: 13 существующих регрессий игровой логики и 2 проверки ресурсов/атласа.
- Локальная production-сборка и Poki-сборка успешно собираются. Архивы не создавались.
- 139 файлов локальной web-сборки, около 6.12 МБ без сжатия HTTP. Phaser находится в отдельном бандле, около 358 КБ gzip. Предупреждение Vite о большом JS-чанке относится к полному движку.
- Исходные PNG-листы `public/Item` (14.88 МБ), старые карты и оружие исключены из web-сборки. Они остаются в репозитории.
- Браузерный прогон: Chrome/Chromium через Playwright, WebGL со SwiftShader и отдельно Canvas без WebGL. Результаты: `browser-smoke-results.json`.
- Vite development / React StrictMode: после трёх выходов в гильдию и возвратов остаётся один Canvas, ошибок страницы нет.
- Размеры 320×640, 360×640, 390×844, 412×915, 768×1024 и 1440×900: нет переполнения; навигация и все восемь боковых слотов помещаются в экран.
- В успешных сценариях нет ошибок JavaScript и отсутствующих ресурсов. Отдельно намеренно воспроизводится HTTP 503 для проверки восстановления загрузки.

## Проверенные механики

Автоматические тесты сохраняют покрытие предыдущей версии: независимость DPS/клика, десять убийств, ручной переход, фарм, гейты, пакетные покупки, рубежи ×2, трофеи, торговля, заказы, победа над боссом, таймаут, рекламное продолжение на уровне чистой логики, финал 105-й комнаты, нормализация и восстановление сохранения.

Браузер проверяет:

- Единственный Canvas Phaser 4; указатель, касание и клавиатура вызывают атаку.
- Окно экипировки закрывается ударом, а клики по HTML-кнопкам не проходят сквозь окно в Phaser.
- Пауза инвентаря и платформенные события pause/resume.
- Покупка ×10, выход в гильдию, сдача пяти компонентов, продажа, сохранение и перезагрузка.
- Переход по всем шести ярусам в одном экземпляре сцены, повторный вход в кэшированный и выгруженный ярус.
- Убийство касанием меняет спрайт и выдаёт золото.
- Победа над боссом сохраняет награду, открывает следующую комнату и возвращает на предыдущую.
- Истечение настоящего 30-секундного таймера, бесплатная новая попытка и отсутствие рекламной заглушки в local-режиме.
- Запуск по вложенному URL `/embedded/game/`.
- Ошибка загрузки останавливает урон; повтор восстанавливает сцену без второго Canvas.
- Запасной рендерер Canvas: сцена рисуется и принимает удары.

## Снимки и арт

Дополнительная проверка визуальной обратной связи: золотая пульсация всех семи доступных вещей, отключение после траты золота, доступный рубеж ×2 при максимальном уровне вещи, отсутствие анимации при reduced motion. Проверены след клинка и подсветка фона в WebGL/Canvas, серия из 35 быстрых ударов без ошибок. TypeScript и production-сборка проходят. Кадр попадания: `screenshots/blade-hit-390x844.png`; доступные улучшения: `screenshots/upgrade-ready-390x844.png`.

`docs/screenshots/` содержит реальные снимки боя, экипировки, гильдии, пути, остальных ярусов, победы и режима Canvas. `item-sheets.jpg` показывает все семь исходных листов; `item-sprites.png` — проверенную нарезку. Все 88 врагов и 18 изображений боссов существуют, а выбор спрайта проверен для каждой из 105 комнат.

Браузерные тесты используют изолированные профили. Золото и компоненты в снимках торговли — тестовые; обычный новый профиль не получает их.

## Границы проверки

Реальный телефон, длительная нагрузка и прохождение всей экономики требуют игрового тестирования. Poki Inspector и реальные рекламные показы не выполнялись; проверена сборка и сохранена прежняя платформенная интеграция. Облачные сохранения новой схемы не добавлены. Изображений боссов 18 на 21 встречу: последние три используют повтор, как в исходной версии. Покадровых анимаций монстров в предоставленных ресурсах нет.

## Повторить

```sh
npm ci
npm test
npm run build
node tests/idle/browser-smoke.cjs
```

Для браузерного теста нужен Playwright и Chromium; переменные `PLAYWRIGHT_MODULE` и `PLAYWRIGHT_BROWSER` позволяют использовать уже установленный runtime и браузер. Скрипт сам поднимает временный HTTP-сервер и сохраняет результаты. На Windows игру запускает `START-DEV.cmd`, готовую сборку — `START-PREVIEW.cmd`.
