# Проверка Idle Dangerous 0.1.0

12 сентября 2026. Проверялась локальная production-сборка, а не старый экран Clicker Weapon Adventure.

## Выполнено

- TypeScript: `npm run check` — без ошибок.
- `npm test` — 13 регрессионных тестов новой логики пройдены.
- `npm ci --dry-run --ignore-scripts --offline` — package.json и исправленный package-lock.json согласованы.
- `npm run release:poki` и `npm run release:local` — сборка и упаковка проходят.
- Браузерный smoke-test production через Chromium — пройден. Результат: `browser-smoke-results.json`.
- Размеры 320×640, 360×640, 390×844, 412×915, 768×1024 и 1440×900: нет горизонтального переполнения, нижняя навигация и восемь боковых слотов находятся в окне.
- В проверенных сценариях нет JavaScript-ошибок страницы и отсутствующих ассетов.

## Проверенные механики

Независимость DPS и клика; десять убийств и ручной переход; повторный фарм; гейты вещей; покупка пачки без отрицательного золота; отдельные рубежи ×2; выпадение трофеев; запрет продажи вне гильдии; продажа без дублирования; сдача пяти с сохранением точной суммарной стоимости; победа над боссом один раз; таймаут, повтор и рекламное продолжение на уровне игровой логики; финальный босс; восстановление экипировки/добычи/гильдии/cooldown; повреждённые сохранения; отмена босса при выходе.

В браузере дополнительно проверены открытие окна вещи, закрытие ударом, пауза при открытом инвентаре, покупка ×10, переход в гильдию, сдача пяти предметов, продажа остатка, перезагрузка без восстановления проданных предметов, выбор босса через путь, выход и повторный вход с новым таймером.

## Снимки

`docs/screenshots/`: бой 390×844 и 320×640, окно экипировки, гильдия и путь. Это реальные снимки собранной игры. Для проверки торговли использовался тестовый профиль с компонентами; новый пользователь начинает без тестового золота и вещей.

## Что ещё требует проверки

- Реальный телефон, производительность длительной сессии и поворот устройства. Эмуляция viewport не заменяет телефон.
- Полное прохождение 105 комнат и длительность поздней экономики. Базовые кривые исходника сохранены, но новый дополнительный доход не прошёл retention-плейтест.
- Poki Inspector, настоящий SDK-рекламный показ, аккаунты и облачный прогресс. Автоматический тест подтверждает игровую логику продолжения, но не успешную интеграцию с рекламным сервером.
- GamePush cloud save новой схемы не подключён.
- Финальные иконки экипировки, компоненты и уникальные подземные фоны остаются отдельным арт-этапом.

## Повтор проверки

```
npm ci
npm test
npm run build
```

Необязательный браузерный прогон: установите Playwright и его Chromium, затем `node tests/idle/browser-smoke.cjs`. Если браузер уже установлен в окружении, можно указать `PLAYWRIGHT_MODULE` и `PLAYWRIGHT_BROWSER`. Скрипт сам открывает локальный HTTP-сервер, использует отдельный тестовый профиль и сохраняет снимки.
