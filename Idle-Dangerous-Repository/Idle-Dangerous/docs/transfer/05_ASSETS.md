## Каталог

Откройте `catalog.html` обычным браузером после распаковки — интернет не нужен. Можно искать по имени, роли и категории; оригинальные картинки показываются рядом с метаданными. JSON/CSV содержит каждый оригинальный файл, статус использования, размер, alpha-bbox, SHA-256 и путь к PNG-копии. Для изображений SVG размеры могут определяться через viewBox; отсутствие растровой ширины в записи не означает повреждение.

ACTIVE — используется текущей игрой или её web-оболочкой. SOURCE — листы/метаданные происхождения. LEGACY — сохранено из старой игры, сейчас не подключено. LICENSE — текст условий шрифта. Все материалы сохраняются в исходном виде независимо от статуса.

## Нарезка

У отдельных иконок итоговый холст 160×160, содержимое вписано в 144×144 и центрировано, фон прозрачный. Атлас использует те же холсты. В sources.json прямоугольники имеют вид [left, top, right, bottom], начало координат сверху слева; правая/нижняя границы исключаются. Не считать эти числа [x,y,width,height]. Из нерегулярной ячейки выделяется крупнейшая связная непрозрачная область, затем сохраняются сглаженные края. Инструмент `05_SOURCE_PROJECT/scripts/prepare-idle-art.py` воспроизводит текущую нарезку.

Для нового движка проще импортировать готовые отдельные PNG. Если нужна нарезка атласа в системе с началом координат снизу слева, пересчитать Y как `высота атласа − y − h`; координаты JSON даны сверху слева. Исходные Item содержат много неиспользованных вещей — они не являются новыми доступными предметами игры.

## Перенос в сцену другого движка

Организовать ресурсы по назначению: Backgrounds / Enemies / Bosses / Equipment / Materials / VFX / UI / Audio / Fonts. Стабильные ID из 06_DATA связывают таблицы с картинками. Сохранить исходные имена в метаданных импорта, чтобы можно было проверить происхождение.

Прозрачные картинки импортировать как 2D-спрайты с alpha; сглаживание линейное, не pixel-art. Монстр имеет pivot снизу по центру, предметы/эффекты — в центре. Не применять фоновый цвет к прозрачным PNG. Размер игрового объекта определяется раскладкой сцены, а не физическим числом пикселей изображения. Background — cover; предметы и враги — contain. Смешивание glow — additive, обычные изображения — стандартная alpha-композиция.

Это рекомендации по организации переноса, не существующая структура Unity-проекта. Выбор Canvas, UI Toolkit, префабов и механизма хранения принадлежит целевой реализации. Нельзя полагаться на имена шейдеров или API из web-источника.

## Происхождение и наличие

Только Roboto имеет явно приложенную лицензию OFL. Для остальных материалов отдельные документы происхождения/лицензирования в проекте не найдены; архив передаёт существующие файлы, не присваивает им новую лицензию. Папка ART на верхнем уровне текущего проекта пустая. Несуществующие PSD, модели, скелеты и кадровые анимации в состав не заявлены.
