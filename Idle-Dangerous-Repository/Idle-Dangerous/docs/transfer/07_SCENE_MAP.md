# Что где находится: схема сборки экранов

Имена ниже — предложенная понятная иерархия объектов для нового проекта, не обязательные имена классов или префабов. Родители управляют расположением, дети — изображениями и действиями. Стабильные ID предметов и компонентов следует сохранить.

```text
GameRoot — одна вертикальная колонка
├── TopToolbar — Настройки, Звук
├── ResourceBar
│   ├── Gold — coin + gold
│   ├── Diamonds — diamond + diamonds
│   ├── TotalDamage — сумма DPS
│   └── ClickDamage — ручной урон, переход в тренировку
├── DungeonContent [когда location=dungeon]
│   ├── RegionHeader — подпись яруса, имя, кнопка карты
│   ├── LevelCarousel — стрелка, прокручиваемые 105 карточек, стрелка
│   ├── RoomProgress — номер, 10 сегментов, счётчик/босс
│   ├── Arena
│   │   ├── Background — zone-NN, заполнение с обрезкой
│   │   ├── DarkVeil — затемнение фона
│   │   ├── HitBackgroundLight — мягкий свет ПОЗАДИ врага
│   │   ├── GroundShadow — эллипс под ногами
│   │   ├── Enemy — один текущий спрайт
│   │   ├── HitArea — центральная область ввода
│   │   ├── CombatEffects — клинок, искры, цифры, монета/компонент
│   │   ├── ForegroundShade — верх/низ темнее
│   │   ├── EnemyHeader — тип, имя, HP, таймер босса
│   │   ├── GearLeft — helmet, armor, bracers, boots
│   │   ├── GearRight — shoulders, ring, amulet, focus
│   │   ├── TapHint — подсказка нажатия
│   │   ├── GearPopover — окно выбранной вещи
│   │   ├── VictoryOverlay — победа 1,8 секунды
│   │   └── LoadingOverlay — загрузка или повтор
│   ├── Notice — последнее событие
│   └── TravelActions — гильдия / следующий уровень ↑
├── GuildContent [когда location=guild, вместо DungeonContent]
│   ├── EmblemAndTitle — символ ◈ и заголовок
│   ├── RankAndReputation
│   ├── InventorySummary
│   ├── MaterialRows — 6 строк, индивидуальная продажа / заказ
│   ├── SellAll
│   ├── TradeNotice
│   └── ReturnToDungeon / OpenPath
├── BottomNavigation — 4 вкладки, бейдж рюкзака
├── ModalLayer — затемнение и одно выбранное окно
│   ├── Inventory / Training / Path / Settings / Help
│   └── BossTimeout — отдельный выбор после поражения
├── StartOverlay — блокирует игру до входа
└── SaveWarning — поверх UI, если запись невозможна
```

Разные системы рендера могут требовать отдельный Canvas или слой сортировки для эффектов и интерфейса. Важно воспроизвести видимый порядок, а не механически сделать каждый пункт отдельной сценой. Гильдия и модальные окна не должны создавать второй независимый игровой прогресс.

## Связь визуального объекта с ресурсом и состоянием

| Объект | Откуда изображение | Откуда значение / правило |
|---|---|---|
| Gold | art/effects/coin.webp | gold, меняется при убийстве/золотой покупке |
| Diamonds | Generated/diamond.svg или PNG | diamonds, меняется при торговле |
| Background | art/backgrounds/zone-01…06.webp | region текущего room из regions.json |
| Enemy | art/enemies или art/bosses | список и индекс из 01_GAME / levels.json |
| helmet…amulet | art/items/{ID}.webp или PNG | gear[ID], порог и цены equipment.json |
| focus | art/abilities/strength.webp | clickLevel, focusUntil, focusReady |
| MaterialRows | art/items/{ID}.webp или PNG | inventory[ID].count/value, materials.json |
| HP | прямоугольники и текст | hp / hpMax текущего врага |
| RoomProgress | десять маленьких прямоугольников | kills 0…9, для босса особый цвет |
| Карточки уровней | градиент, рамка, номер, символ | room / highest / defeated |
| Карта пути | круг, линия, подписи | те же данные; визуальный порядок 105→1 |
| GearPopover | те же иконки + стандартная панель | выбранный ID вещи, допустимые покупки |
| HitBackgroundLight | Generated/blade-glow.png | событие успешного ручного удара |
| HitSlash | Generated/blade-slash.png | чередование направления + случайный небольшой поворот |
| LootPopup | coin + art/items/{drop}.webp | результат убийства, без повторного начисления |

Пути art/... в таблице находятся внутри `03_ASSETS/public/`, PNG-дубликаты — `03_ASSETS/PortablePNG/`. Для самого механизма анимации нужна временная шкала параметров, описанная в 02_STYLE_AND_EFFECTS.md, а не только картинка.

## Связь события и результата

| Событие | Экономическое действие | Видимый результат |
|---|---|---|
| Нажатие врага | Вычесть ручной урон один раз | Закрыть окно вещи, удар/свет/число/звук |
| Автошаг | Вычесть DPS×0,2 | Обновить HP; ручной эффект не запускать |
| Смерть | Начислить золото, случайную добычу, прогресс | Монета/материал, смена врага, уведомление |
| Открыт этаж | Повысить highest | Карточка становится доступной; активный уровень прежний |
| Купить вещь/уровень/рубеж | Вычесть золото, увеличить силу | Пересчитать DPS, цены и ВСЕ жёлтые сигналы |
| Продать/сдать заказ | Вычесть стек, добавить алмазы, при заказе репутацию | Новые суммы и сообщение результата |
| Выбрать этаж | Проверить доступ, сбросить бой новой комнаты | Поменять фон/врага при необходимости, центрировать ленту |
| Открыть модальное окно | Экономика прежняя | Пауза боя, затемнение, фокус в окне |
| Закрыть приложение | Записать прогресс | При повторном запуске стартовый экран, без офлайн-дохода |

## Где уточнить по справочному исходнику

В `05_SOURCE_PROJECT/src/idle/Game.tsx` — состав экранов, подписи, реакции UI, сохранение. `engine.ts` — правила и состояние. `art.ts`, `enemies.json` — соответствия изображений. `LevelCarousel.tsx` — лента. `phaser/DungeonScene.ts` — композиция арены, время и эффекты. `Icons.tsx` — алмаз и картинки. `idle.css` — конечные стили. Только четыре формулы из `src/game/clickerV3.ts` используются новой экономикой; прочий старый арсенал в `src/game/Game.tsx` не активен. Эта карта исходника приложена для проверки нюансов, а не как требование сохранять язык или движок.
