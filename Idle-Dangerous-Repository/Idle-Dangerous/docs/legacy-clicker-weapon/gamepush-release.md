# Подготовка билда для GamePush

Дата актуализации: 2026-09-02<br>
Статус: `build_pipeline_ready`

## Конфигурация

1. Скопировать `.env.example` в `.env.local`.
2. Заполнить публичные значения:

```dotenv
VITE_GAMEPUSH_ENABLED=true
VITE_GAMEPUSH_PROJECT_ID=your_project_id
VITE_GAMEPUSH_PUBLIC_TOKEN=your_public_token
```

Секретный ключ нельзя помещать в Vite-переменные или архив игры.

## Сервисы

- `src/platform/gamepush.ts` загружает SDK и управляет рекламой/паузой.
- `Modules/analytics/GamePushAnalyticsAdapter.ts` отправляет игровые цели.
- `Modules/saves/GamePushSaveAdapter.ts` записывает версионированное сохранение в поле игрока.
- `Modules/leaderboards/GamePushLeaderboardAdapter.ts` отправляет и получает рейтинги.
- `Modules/identity/GamePushIdentityAdapter.ts` предоставляет состояние авторизации игрока.

В панели GamePush необходимо заранее создать строковое поле `save_data`, настроить таблицы рейтингов и проверить авторизацию на каждой целевой площадке.

## Кросс-девайс сохранение

Авторизованный игрок должен получить одно сохранение на компьютере и телефоне в рамках одного и того же аккаунта/площадки. Гостевой прогресс остаётся локальным. Перенос между независимыми аккаунтами Poki, Яндекса, VK и других площадок автоматически не обещается.

## Сборка

```bash
npm run release:gamepush
```

Результат: `release/mage-cleanse-gamepush.zip`. `index.html` должен находиться в корне ZIP.

## Проверка перед загрузкой

- SDK и player API готовы до чтения облачного сохранения;
- локальная копия не стирается при ошибке сети;
- конфликт двух устройств разрешается по revision/updatedAt;
- реклама останавливает звук, ввод, автоурон и таймер босса;
- rewarded-награда выдаётся только после подтверждённого просмотра;
- лидерборд не отправляется после каждого клика;
- мобильный и desktop UI работают из одной сборки.

Официальная справка: [GamePush SDK](https://gamepush.com/sdk/docs/).
