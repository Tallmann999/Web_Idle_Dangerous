# Архитектура Idle Dangerous

React 19 + TypeScript + Vite. Сохранён стек исходного проекта, платформа и библиотека старых ассетов. Unity/Phaser не требуются.

| Файл | Роль |
|---|---|
| `src/main.tsx` | Инициализация платформы и запуск нового экрана |
| `src/idle/Game.tsx` | Вертикальный интерфейс, единый heartbeat, окна, звук, сохранение |
| `src/idle/engine.ts` | Состояние, вещи, трофеи, покупки, комнаты, боссы, гильдия |
| `src/idle/Icons.tsx` | Векторные иконки экипировки, компонентов и каменный свод |
| `src/idle/idle.css` | Адаптивная композиция и эффекты |
| `src/idle/enemies.json` | Манифест существующих монстров по шести ярусам |
| `src/game/clickerV3.ts` | Переиспользуемые исходные формулы HP, золота и тренировки |
| `src/platform/` и `Modules/` | Перенесённая инфраструктура платформ; новый save описан ниже |
| `public/art/`, `public/audio/`, `public/fonts/` | Исходные игровые ресурсы |
| `tests/idle/engine.test.mjs` | Регрессии новой игры |
| `scripts/package-idle.mjs` | Переносимая упаковка готовой web-сборки |

Старый `src/game/Game.tsx` сохранён для истории и сравнения. Он не импортируется точкой входа новой игры. Нельзя править его в расчёте на изменение активного интерфейса. Основной код новой игры — `src/idle/`.

## Состояние и сохранение

Новый независимый localStorage-ключ: `idle-dangerous-save-v1`, схема 1. Старые weapon-save не читаются и не перезаписываются. Это новая игра, поэтому первый вход начинает её с нуля.

Сохраняются золото, текущая и максимальная комната, счётчик убийств, HP обычного врага, экипировка с рубежами, уровень клика, компоненты с суммарной стоимостью, репутация, местоположение (гильдия/подземелье), прохождение финала, звук и таймеры настройки.

Запись: покупки, убийства, смена комнаты/места, продажа, скрытие вкладки, `pagehide`, резервный интервал 15 секунд. Ошибки localStorage показываются игроку без прекращения игры. При загрузке числовые поля ограничиваются; некорректный или чужой формат даёт новое состояние.

Прерванная попытка босса начинается заново. Межсессионного урона и offline-дохода нет. Таймеры «Настроя» основаны на календарном времени, время боя — на активной симуляции.

## Паузы

Инвентарь, путь, тренировка, помощь, гильдия, стартовый экран, реклама, скрытая вкладка и сцена победы приостанавливают симуляцию. Окно экипировки не останавливает бой. Lifecycle платформы следует этому состоянию. Звук атаки использует один переиспользуемый Audio-объект. VFX ограничены шестью импактами.

## Платформы

`npm run build` создаёт локальный web-build. `npm run build:poki` выбирает `.env.poki`, подключает сохранённый platform bridge и Poki SDK, исключает GamePush из Poki-бандла. На локальной сборке нет имитации успешной рекламы.

Новая игра хранит прогресс локально в отдельном ключе. Верификация платформенной облачной синхронизации, аккаунтов, аналитики новой экономики и таблиц лидеров не выполнена. GamePush cloud save новой схемы к интерфейсу не подключён. Старый инфраструктурный код сохранён как заготовка и не является подтверждением готовности этих функций.

Публикация на Poki не выполнялась. Перед релизом нужны проверка текущих требований площадки, Inspector, реальная реклама и тест на телефоне. В проекте не следует использовать данные старого Sites-проекта: это самостоятельный локальный форк, предназначенный для скачивания.
