# Перенос Idle Dangerous на Phaser 4

12 сентября 2026. Движок: npm `phaser@4.2.1`, версия закреплена в package-lock.json.

## Что обнаружено в репозитории

Активная игра запускается из `src/main.tsx` → `src/idle/Game.tsx`. `src/game/Game.tsx` и документы `docs/legacy-clicker-weapon` содержат предыдущую игру с оружием, картой и платформенными модулями. Новая версия сознательно сохраняет механику Idle Dangerous: старые оружейные умения и карты не возвращены. Git до переноса содержал один начальный коммит.

В `public/art` уже находятся 88 вырезанных WebP-врагов, 18 боссов, 6 фонов ярусов, монета, способности, а также неиспользуемые текущей игрой карты и оружие. В `public/Item` — 7 прозрачных PNG-листов 1254×1254 с нерегулярной раскладкой:

## Реализация

- Phaser.Game / DungeonScene рисуют фон, тень, монстра, попадания, числа урона и вылетающие монеты/компоненты.
- Цикл боя перенесён из React setInterval в Phaser update. Phaser Input обрабатывает мышь и касания; клавиатура вызывает ту же команду атаки.
- HTML HUD сохранён для адаптивности, прокрутки, модальных окон и клавиатурной навигации. Это игра на Phaser с HTML-интерфейсом, а не полная перерисовка меню в Canvas.
- Используются прежние пулы монстров и формула их смены. Сюжетных боссов 21, готовых изображений 18: последние три повторяют начало набора, как и до переноса.
- Фоны видны напрямую, временный SVG-коридор удалён. Имеющиеся фоны изображают леса, снег и Бездну; названия шести игровых ярусов сохранены.
- Нарезанные иконки имеют прозрачность, размер 160×160 и внутренние поля. Для эффектов собран Phaser JSON Hash-атлас 640×640; для HTML используются отдельные WebP.
- `public/art/items/sources.json` сохраняет связь каждой иконки с исходным PNG и прямоугольником. `python scripts/prepare-idle-art.py` воспроизводит экспорт; необходим Pillow.
- Статичные монстры используют появление и реакцию на удар. Покадровой анимации ходьбы в исходных материалах нет.

## Совместимость

Сохранены 105 комнат, ручной переход после десяти убийств, боссы по 30 секунд, 7 слотов с пакетами и рубежами ×2, тренировка, настрой, 6 компонентов, инвентарь, гильдия, продажа, заказы и репутация. Баланс и функции `engine.ts` не менялись. Ключ сохранения `idle-dangerous-save-v1` и схема 1 прежние. Прерванный босс начинает новую попытку, как раньше.

`preview/idle-dangerous.html` — исторический экспорт до миграции. Актуальная сборка создаётся через `npm run build` и открывается на HTTP-сервере. ZIP создаётся только отдельной явной командой; при этой миграции архив не создавался.
